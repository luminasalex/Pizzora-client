# Copilot instructions

## Project shape

- This repository is a Next.js App Router application using TypeScript and React. Routes live under `app/`; `app/layout.tsx` wraps pages with the shared `Navber` and `Footer`, and imports the global stylesheet.
- Authentication is handled by Better Auth: `app/api/auth/[...all]/route.ts` exposes its Next.js handlers, `lib/auth.ts` configures the server-side auth and MongoDB adapter, and `lib/auth-client.ts` contains the browser client.
- Shared UI primitives are local shadcn components in `components/ui/`, configured by `components.json` to use the `base-nova` style and Base UI. `components/` also holds app-level shared components; reusable hooks are in `hooks/`.
- Styling uses Tailwind CSS v4 through imports in `app/globals.css`; shadcn's CSS is imported there as well. The `@/*` TypeScript alias maps to the repository root.

## Repository-specific guidance

- This checkout's Next.js version has breaking changes: before changing Next.js code, consult the relevant guides under `node_modules/next/dist/docs/` from this repository and follow their current APIs. The Next.js-generated section above is regenerated by `next dev`; do not remove it.
- Keep route-specific rendering and data flow in the App Router structure. Components are Server Components by default; mark a component with `"use client"` when it needs client-side hooks, browser APIs, or event-driven state.
- For UI primitives, inspect and extend the existing local component in `components/ui/` before adding another copy. Preserve the project's shadcn configuration and aliases in `components.json`.
- Follow the existing formatting configuration: no semicolons, double quotes, two-space indentation, and Tailwind class sorting via the configured Prettier plugin. `npm run format` writes across TypeScript files; to format one file, use `npx prettier --write path/to/file.tsx`.
- Keep server auth configuration in `lib/auth.ts` and route it through the existing catch-all handler; browser auth usage belongs in `lib/auth-client.ts`. Do not expose server-only credentials or database configuration to client code.
